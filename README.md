# Ch-ch-chains 🔗 המשחק של עמך ישראל

משחק רשת לטלפון בסגנון slither.io: אוספים ניצוצות, נותנים יד ומתארכים.
**לבד אתה חזק – ביחד אנחנו שרשרת.**

▶️ **לשחק:** https://chchchains.onrender.com

## איך משחקים

- 👆 גוררים אצבע לכיוון שרוצים ללכת
- ⚡ מחזיקים כדי להאיץ (זה עולה קצת אורך)
- 🤝 נותנים יד למי שקרוב: חברים באותה שרשרת עוברים זה דרך זה, ואוספים פי 1.5 כשהם קרובים (עד 4 בשרשרת)
- נתקלים בשרשרת של מישהו אחר או יוצאים מהמפה? השרשרת נקרעת לניצוצות שכולם יכולים לאסוף

## עקרונות

- בלי הרשמה, בלי עוגיות ובלי מעקב. כתובות IP משמשות רק בזיכרון של השרת כדי להגביל חיבורים, ולא נשמרות או נרשמות ביומן.
- השמות נבחרים מתוך רשימה מוכנה (״ניצוץ זריז״, ״גל מהנגב״…), כך שאין טקסט חופשי שצריך לסנן.
- בוטים מסומנים תמיד ב־🤖. כשמעט אנשים משחקים, בוטים ממלאים את החדר.
- קוד פתוח ברישיון MIT.

## איך זה בנוי

| קובץ | מה יש בו |
| --- | --- |
| `src/sim.js` | הסימולציה: תנועה, התנגשויות, ניצוצות, ידיים, בוטים. אותו קוד רץ בדפדפן (משחק עם בוטים) ובשרת |
| `src/client.js` | ציור, מגע, מסכים, לוח מובילים ושיתוף |
| `src/net.js`, `src/protocol.js` | משחק רשת: השרת שולח 15 תמונות מצב בשנייה; גוף של שרשרת נשלח פעם אחת ואחר כך רק הנקודות החדשות, כך ששחקן מקבל כ־4KB לשנייה. הדפדפן מצייר כעשירית שנייה ״באיחור״ כדי שהתנועה תהיה חלקה |
| `server.mjs` | שרת Node בלי תלויות: דף המשחק ו־WebSocket, חדרים של עד 40 איש |
| `build.mjs` | בונה את הכול לקובץ HTML אחד ב־`docs/` |

## הרצה מקומית

```sh
npm test            # בדיקות
node build.mjs      # בונה את docs/index.html
node server.mjs     # http://localhost:3000
```

`?stats` בסוף הכתובת מציג קצב פריימים ונתוני רשת.
`node scripts/loadtest.mjs ws://localhost:3000/ws 40 60` מדמה 40 שחקנים במשך דקה.

## העלאה לאוויר בחינם

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/boggioMichael/chchchains)

הכפתור יוצר ב־Render את שני החלקים שב־`render.yaml`:

- **chchchains**: דף המשחק, אתר סטטי על ה־CDN של Render. נטען מיד ולא נרדם אף פעם.
- **chchchains-server**: שרת המשחק, שירות חינמי שנרדם אחרי 15 דקות בלי שחקנים. כשמישהו נכנס, הדף מעיר אותו (בערך דקה), ובינתיים משחקים עם בוטים. מהסיבוב הבא כבר משחקים עם אנשים.

כל שינוי שנדחף ל־`main` עולה לאוויר לבד.

## הגדרות

בנייה (`config.json` או משתני סביבה):

| משתנה | משמעות |
| --- | --- |
| `CHAIN_SERVER` | כתובת השרת, למשל `wss://chchchains-server.onrender.com/ws`. ריק: משחק עם בוטים בלבד |
| `CHAIN_BRAND` | שורת המותג מתחת לשם המשחק |
| `CHAIN_PUBLISHER` | שורת ״פורסם על ידי״ בתחתית המסך |
| `CHAIN_JOIN_URL` | קישור להצטרפות שמופיע אחרי כל סיבוב (לא חובה) |
| `CHAIN_SHARE_URL` | הכתובת שמשותפת ושמופיעה בתמונת השיתוף |

שרת:

| משתנה | ברירת מחדל | משמעות |
| --- | --- | --- |
| `PORT` | 3000 | |
| `ALLOWED_ORIGINS` | הכול | אתרים שמותר להם להתחבר, למשל `https://chchchains*.onrender.com` |
| `MAX_CLIENTS` | 300 | מקסימום מחוברים; מעבר לזה משחקים עם בוטים |
| `ROOM_CLIENTS` | 40 | אנשים בחדר |
| `BOT_FILL` | 18 | כמה שרשראות חדר מחזיק כשמעט אנשים משחקים |
| `MAX_PER_IP` | 60 | חיבורים מאותה כתובת (ברשתות סלולר הרבה אנשים חולקים כתובת) |
| `TRUST_PROXY` | פעיל ב־Render | לקחת את כתובת השחקן מ־`X-Forwarded-For` |
| `LOG` | | `off` משתיק את יומן השרת |

## קיבולת

נמדד: 40 שחקנים בחדר אחד צורכים כ־9% מליבת מעבד אחת וכ־4KB לשנייה לשחקן. השרת החינמי של Render (0.1 מעבד) מחזיק בערך 40 איש בו־זמנית, ולכן `MAX_CLIENTS` מוגדר ל־40. כשזה מתמלא: משדרגים את השירות ב־Render (Starter, 0.5 מעבד) ומעלים את `MAX_CLIENTS`.

## לפני פרסום רשמי

אם המשחק מתפרסם רשמית מטעם התנועה, צריך אישור שלה ושורת מפרסם ברורה (`CHAIN_PUBLISHER`), כמו כל חומר תעמולה. כדאי לבדוק את הנוסח עם היועץ המשפטי של הקמפיין.

השם הוא מחווה לגמגום המפורסם בשיר ״Changes״ של דייוויד בואי.

English: a free, open-source (MIT) multiplayer phone game in the spirit of slither.io. Collect sparks, give a hand to form a chain, grow together. Zero-dependency Node server with a hand-written WebSocket layer, delta-compressed snapshots and client-side interpolation; the same simulation runs in the browser for offline play with labelled bots.
